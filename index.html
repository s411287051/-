基礎

0. 機器視覺概論與 AOI 定義

機器視覺以非接觸方式擷取影像並分析，AOI 是其最重要的工業檢測應用之一。

  • 六大功能：定位、識別、辨識、瑕疵檢測、驗證、量測
  • 適合高速、重複性、需穩定度的工作
  • 常見工具：Blob、Pattern Matching、OCR、CNN
展開詳細筆記

機器視覺 Machine Vision 模仿人類視覺，以相機、鏡頭、光源與演算法取代人工目視檢查， 能在產線中以穩定且高速的方式完成品質判斷。自動化光學檢測 AOI 則是機器視覺在製造業中 最典型的應用，主要目的在於改善人工檢測速度慢、疲勞造成穩定性差與漏檢等問題。

AOI 系統通常整合光學機構設計、機台設計、運動控制、系統整合、影像前處理、影像後處理、 尺寸量測與瑕疵檢測。瑕疵檢測難點在於瑕疵位置不固定、形狀未知；門檻太鬆會漏檢， 太嚴則會增加假警報，因此需在 Recall 與 Precision 間取得平衡。

光學

1. 光源與照明設計

照明是 AOI 的關鍵，好的打光能凸顯瑕疵、壓抑背景，讓演算法更穩定。

  • LED 是 AOI 主流光源，壽命長、可閃頻、亮度易控制
  • 明視野適合反射差異，暗視野適合刮痕與微小缺陷
  • 背光適合輪廓量測與尺寸檢測
展開詳細筆記

鎢絲燈亮度高但熱量大、壽命短；氙氣燈亮度極高且可短時間閃光，但供電複雜且昂貴； 螢光燈成本低且照射面積大，但壽命短、光譜不均且不適合閃頻；LED 具備低熱、低耗電、 壽命長、可閃頻控制、亮度易調整與可組成任意形狀等優點，因此是 AOI 主流光源。

明視野 Bright Field 讓相機位於鏡面反射路徑，主要呈現反射率差異；暗視野 Dark Field 讓相機偏離反射方向，接收刮痕、灰塵與邊緣散射光；穿透光 Backlight 從物體後方打光， 可產生清楚輪廓，適合外形與尺寸量測。

取像

2. 相機與鏡頭搭配原理

正確取像需理解焦距、物距、像距、倍率、感測器尺寸與視野幅。

  • 成像公式：1/f = 1/u + 1/v
  • FOV = Sensor Size / Magnification
  • Image Circle 必須覆蓋 Sensor 對角線避免暗角
展開詳細筆記

放大倍率 α = v/u = d/D，其中 d 為像面尺寸，D 為物面尺寸。相同倍率下，焦距越長通常 工作距離越長，可避免機構干涉。像素解析度可由 Pixel Size / α 估算，例如 Pixel Size 3.45μm、倍率 0.5x 時，物面解析度約 6.9μm。

鏡頭成像為圓形 Image Circle，而 Sensor 為矩形，因此 Sensor 對角線需小於等於 Image Circle， 否則畫面邊緣會出現暗角。C Mount 法蘭距為 17.526mm；CS Mount 為 12.5mm， CS 相機可加 5mm 延伸環使用 C Mount 鏡頭。

取像

3. 相機規格與取像參數

曝光、光圈與增益會直接影響亮度、景深、雜訊與運動模糊。

  • Rolling Shutter 逐行曝光，動態物體易形變
  • Global Shutter 適合高速移動或旋轉物件
  • 優先順序：對焦清楚 ＞ 不過曝 ＞ 亮度適中
展開詳細筆記

Rolling Shutter 是逐行曝光，物體移動時可能產生果凍效應；Global Shutter 則是全畫面同時曝光， 適合高速產線。傳輸介面可依需求選 GigE、USB3.0、Camera Link 或 CoaXPress。

光圈 F# = 焦距 / 光圈直徑。F# 越小進光量越多但景深較淺；曝光時間越長越亮但容易產生運動模糊； Gain 可補亮但會同步放大雜訊。工業取像應優先對焦與避免過曝，因為失焦與高光細節遺失通常無法後製救回。

影像處理

4. 彩色成像與影像品質

影像品質受到色彩取樣、SNR、動態範圍與亮度均勻性影響。

  • Bayer Pattern 成本低，但需插值補色
  • SNR 影響細小瑕疵可辨識性
  • Dynamic Range 影響亮暗細節保留
展開詳細筆記

Bayer Pattern 在感測器上貼 RGGB 濾光片，再由鄰近像素插值補齊缺少色彩，成本低但解析度會下降。 3CCD 使用稜鏡分光，RGB 各由獨立感測器接收，畫質最佳但成本最高。 若檢測只需要灰階資訊，應直接選用灰階相機，而非彩色相機拍攝後再轉灰階。

SNR 訊號雜訊比用來衡量畫面純淨度，對於單一 pixel 或極小瑕疵特別重要。 Dynamic Range 則是同時捕捉亮部與暗部細節的能力。影像品質可透過白平衡、亮度均勻校正與對比擴張改善。

影像處理

5. 數位影像空間域處理

以 Kernel 對像素鄰域運算，完成平滑、銳化、對比增強與邊緣偵測。

  • 中值濾波適合椒鹽雜訊
  • 高斯濾波可平滑高頻雜訊
  • Sobel / Prewitt / Laplacian 可強化邊緣與孔洞特徵
展開詳細筆記

強度轉換包含二值化、負片 s=255-r、對數轉換與 Gamma 轉換。直方圖等化透過累積分布函數重新映射灰階， 可提升對比。均值與高斯濾波屬於低通平滑方法，其中高斯濾波因中心權重較高，影像較不易過度模糊。

Sobel 與 Prewitt 是一階微分，可偵測水平、垂直與斜向邊緣。Laplacian 是二階微分， 具有等向性，常用於影像銳化與孔洞、裂縫等特徵強化。

影像處理

6. 影像分割與二值化

分割將影像分成目標與背景，是 AOI 找出瑕疵區域的關鍵步驟。

  • 全域門檻簡單但易受光照不均影響
  • Otsu 可自動尋找最佳門檻
  • 區域成長適合光照不均或區域特徵明顯的場景
展開詳細筆記

全域門檻化將大於 T 的像素視為前景，小於 T 的視為背景。反覆式門檻會先估初始值， 再分群計算平均值並更新門檻直到收斂。Otsu 方法會尋找使類別間變異數最大的門檻， 是常見自動二值化方法。

區域成長法從種子點出發，依灰階、紋理或標準差等相似性準則向外擴展。 區域分裂與合併使用四分樹概念，不滿足述詞則切分成四象限，滿足條件的相鄰區域再合併。

影像處理

7. 頻率域濾波

影像可視為不同頻率的組合，高頻代表邊緣與細節，低頻代表平滑背景。

  • FFT 可將影像轉為頻譜分析
  • 低通濾波平滑，高通濾波銳化
  • 理想濾波器易振鈴，高斯濾波較平順
展開詳細筆記

頻域濾波流程為影像前處理、傅立葉轉換、乘上濾波器 H(u,v)、反傅立葉轉換與後處理。 低通濾波通過低頻並衰減高頻，可用於平滑；高通濾波通過高頻並衰減低頻，可增強邊緣與細節。

理想濾波器因截斷太硬，容易在邊緣產生振鈴現象。Butterworth 濾波較平滑， 二階以下通常較不易振鈴；高斯濾波最平順，因此常用於避免震盪。

影像處理

8. 形態學影像處理

以結構元素處理二值影像形狀，是 AOI 後處理與瑕疵整理的重要工具。

  • 侵蝕縮小前景、消除小雜訊
  • 膨脹擴大前景、橋接斷線
  • Opening 去雜訊，Closing 填孔洞
展開詳細筆記

侵蝕 Erosion 需結構元素完全包含於前景才保留中心點，可縮小前景、消除小雜訊與分離黏連物件。 膨脹 Dilation 只要結構元素與前景有交集就保留，可擴大前景、填補破碎與連接斷線。

開運算 Opening 先侵蝕再膨脹，能去除凸出的小雜訊；閉運算 Closing 先膨脹再侵蝕， 能填補小孔洞與凹陷。進階操作包含 Hit-or-Miss、Boundary Extraction、Hole Filling、 Connected Components、Skeleton 與 Pruning。

進階

9. 遠心鏡頭與線掃描系統

高精度量測與大面積高速檢測常需遠心鏡頭或線掃描系統。

  • 遠心鏡頭降低透視誤差
  • 線掃描適合 PCB、卷材、玻璃與面板
  • 適合高附加價值與高精度 AOI 任務
展開詳細筆記

一般鏡頭會受到透視影響，物體高度不同時成像尺寸可能改變，造成量測誤差。 遠心鏡頭具備等視角特性，橫向尺寸較不受深度影響，適合精密尺寸量測與孔位檢測。

線掃描相機逐行取像，搭配輸送帶或平台移動重建完整影像，適合大面積、長條狀或連續材料， 如 PCB、玻璃、顯示面板與卷材檢測。

取像

10. 取像參數實務案例

不同場景有不同調整策略，但核心原則都是清楚對焦、避免過曝、控制雜訊。

  • 平面樣品可使用較大光圈提高亮度
  • 有高度差樣品需縮小光圈增加景深
  • 動態樣品需縮短曝光避免運動模糊
展開詳細筆記

平面樣品若幾乎位於同一平面，可使用較大光圈提高進光量，但工業鏡頭通常建議 F4～F8 取得較佳銳利度。若樣品存在高度差，需縮小光圈以增加景深。若物體在輸送帶或旋轉機構上移動， 必須優先縮短曝光時間避免模糊。

曝光不足通常可透過 Gain 或後處理補強，但過曝會造成高光細節永久消失。 Gain 越大畫面越亮，但雜訊也會同步放大，因此應優先調整光源與曝光，再以 Gain 微調。

進階

11. 進階形態學運算

形態學可進一步完成輪廓萃取、孔洞填補、連通元件擷取與骨架化。

  • Boundary Extraction 可萃取物體邊界
  • Hole Filling 可填補封閉孔洞
  • Skeleton 與 Pruning 可整理主幹與刪除寄生枝
展開詳細筆記

Hit-or-Miss 同時考慮前景與背景形狀，可用於偵測特定幾何結構或字元樣式。 Boundary Extraction 可用原圖減去侵蝕後結果取得邊界。Hole Filling 從孔洞內部種子點出發， 反覆膨脹並與補集交集直到收斂。

Connected Components 可區分不同連通物件；Convex Hull 將物體外形包成最小凸形； Thinning / Skeleton 保留主幹拓樸；Pruning 則去除骨架化後不必要的小分枝。

進階

12. 影像特徵表示與描述

分割後需將物件轉成可分析特徵，支援分類、量測與辨識任務。

  • Boundary Representation 適合外形分析
  • Region Description 描述面積、重心、方向與矩
  • 好特徵需具備穩定性、區分力與不變性
展開詳細筆記

Boundary Representation 以輪廓表示物體，適合分析外形變化、曲率、方向與邊界長度。 Skeleton Representation 以骨架描述主要拓樸結構，常用於字元、指紋與路徑分析。 Region Description 則透過面積、重心、方向、矩等特徵描述整體形狀。

好的特徵應具備區分能力、穩定性與不變性，盡可能不受位置、方向、尺寸與光照變化影響， 才能支援可靠分類、量測或辨識任務。

PCB AOI Defect Detection

基於 YOLO 之 PCB 缺孔 (Missing Hole) 瑕疵檢測系統

YOLOv8 OpenCV CLAHE Telecentric Lens AOI

專案核心目標

PCB 缺孔會造成上下層電路無法導通，屬於嚴重製程瑕疵。本專案結合機器視覺硬體取像、 影像前處理與 YOLO 物件偵測模型，建立自動化缺孔檢測流程。

降低 Missing Hole 漏檢風險
分析 PCB 反光與孔洞特徵
使用 YOLO 進行物件偵測
以 Recall 與 mAP 評估成果

光學取像設計

針對 PCB 綠漆與銅箔反光特性，評估光源角度、鏡頭與曝光參數，避免孔洞特徵被反光遮蔽。

影像前處理

使用灰階轉換、CLAHE、濾波與邊緣增強，提升缺孔與背景之間的對比。

YOLO 模型偵測

以邊界框定位缺孔瑕疵，輸出類別與信心分數，支援即時 AOI 檢測需求。

效能評估

重點觀察 Recall、Precision、mAP 與誤判案例，對應工業檢測中漏檢代價高的特性。
